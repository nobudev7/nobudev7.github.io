Run a SpringBoot jar on Docker

Created on August 22, 2023

2023   ·   spring-boot   docker   java   ·   docker   spring

Some articles suggest to run a centos docker image to run SpringBoot app. Since CentOS is deprecated, I found that amazoncorretto is an option.

Dockerfile

FROM amazoncorretto:20

VOLUME [ "/data" ]
ADD MySpringBootApp-0.0.1-SNAPSHOT.jar MySpringBootApp
RUN sh -c 'touch /ValidatingFormInput.jar'
ENTRYPOINT [ "java", "-jar", "/MySpringBootApp" ]

Build Docker image

$ docker build -t myspringbootapp .

Note that the Docker image name has to be lower case.

Run the docker container

$ docker run -p 8080:8080 myspringbootapp
