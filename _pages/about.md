### Distributed Systems & Search Architecture

As a long-time backend engineer and engineering leader, I specialize in high-throughput Java platforms, resilient API design, and distributed architectures that power global search products. My day-to-day focus balances technical strategy with hands-on systems design:

- **Streaming & High-Throughput Sync**: Architecting event-driven messaging pipelines (Kafka) processing 24+ million queries daily, and real-time synchronization systems handling 10+ million live updates per day.
- **Resilient Data Layers**: Optimizing low-latency distributed caching layers, designing custom parsing engines for high-dimensional data, and migrating complex backend APIs to modern microservices.
- **Engineering Leadership**: Guiding vertical backend engineering teams with Agile methodologies, shifting team focus from narrow siloed domains to end-to-end architectural breadth, and fostering cross-functional alignment across Frontend, Product, and Design.

### From Silicon to the Cloud

My passion for software began with a degree in Physics and years developing low-level laboratory instrument drivers. That physical intuition drives my personal projects, where I bridge bare-metal hardware with the cloud:

- **Embedded Drivers & Sensors**: Authoring open-source Python drivers on Raspberry Pi (such as [c4002-python](/projects/) for 24GHz mmWave radar), implementing UART binary framing, background noise calibration routines, and real-time presence tracking.
- **Serverless Cloud Telemetry**: Architecting zero-maintenance, serverless IoT pipelines on AWS ([PiLambdaChart](/projects/), [sumpdata](/projects/))—ingesting edge sensor data into DynamoDB, generating automated charts via scheduled Java Lambda functions, and distributing interactive dashboards globally through Amazon CloudFront and S3.
